# Supplementary Figures

This folder contains exported supplementary-figure scripts from the existing projectome analysis notebooks.

Available entry points:

- `run_soma_distribution.py`
- `run_figure_s6.py`
- `run_supplementary_figures.py`

Run from the repository root:

```bash
python supplementary_figures/run_soma_distribution.py
python supplementary_figures/run_figure_s6.py
python supplementary_figures/run_supplementary_figures.py
```
